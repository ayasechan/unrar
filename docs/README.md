# 文档索引

本文档目录面向本库的开发者与维护者，内容均为自主编写的格式分析与实现说明。

- `architecture.md` — 包结构、核心类型、解压流水线、并发与内存模型、错误设计。
- `rar4-format.md` — RAR4 签名、块头结构、文件头字段、压缩方法版本、solid、注释与服务块。
- `rar5-format.md` — RAR5 签名、自描述头（vint）、块类型、文件头标志、extra 记录、校验。
- `decode-flow.md` — 统一解压流水线：头解析、跨卷拼接、解密、解压、过滤器、校验输出，以及实现要点。
- `volumes-recovery-crypto.md` — 分卷命名与拼接、`.rev` 恢复、加密派生与头加密。
- `development.md` — 构建、测试、fuzz、基准、夹具生成规范与提交前检查。
- `todo.md` — 未实现的已知事项（注释支持、文件名编码夹具、一次遍历提取 API）。

约定：内存中字典上限、跨卷读统一走 `VolumeSet`，密码用完清零。
